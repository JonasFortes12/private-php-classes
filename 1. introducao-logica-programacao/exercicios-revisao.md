## Exercícios de Revisão (lógica básica)


### 1. Menu mini calculadora
Escreva um programa que apresente um menu ao usuário para receber um símbolo do usuário para realizar as seguintes operações:

 - "+": Somar
 - "-": Subtrair
 - "*": Multiplicar
 - "/": Dividir

Após receber o símbolo, o programa deve solicitar dois números ao usuário e realizar a operação correspondente, exibindo o resultado. Caso seja um símbolo diferente dos mostrados no menu, o programa deve informar “Opção inválida!”.


### 2. Cálculo de média
Faça um programa que receba do usuário 4 notas referente a quatro bimestres de um aluno e calcule a média. Se a média for maior ou igual a 7, exiba “Aluno Aprovado”, se a média for menor que 7 e maior ou igual a 5, exiba “Aluno de Recuperação”, se a média for menor que 5, exiba “Aluno de Reprovado”.

### 3. Manipulação de Frutas
Escreva um programa que comece com este array de frutas `frutas=[‘tomate’, ’abacate’, ‘morango’, ‘melancia’]`. Assim, apresente um menu ao usuário e receba um número do usuário correspondente para realizar as seguintes operações:

- `1` – Adicionar uma fruta no fim da lista (usuário informa a fruta a ser adicionada)
- `2` – Remover a última fruta da lista
- `3` – Exibir a(s) n primeiras frutas (usuário informa um número n)
- `4` – Exibir a(s) n últimas frutas (usuário informa um número n)
- `5` – Adicionar uma fruta na posição n (usuário informa um número n e a fruta a ser adicionada)

Por exemplo, se o usuário escolher a `opção 1` e informar a fruta `laranja`, o programa deve adicionar `laranja` ao final da lista de frutas.

Essas opções devem ser utilizadas para realizar as respectivas operações com com os dados fornecidos pelo usuário. Caso seja um número diferente, o programa deve informar “Opção inválida!”.

### 4. Cálculo de Desconto
Crie um programa que peça ao usuário o valor de um produto e um percentual de desconto, depois exiba o valor final com o desconto aplicado.

### 5. Aumento de Salário
Crie um programa que solicite ao usuário um `valor de salário`, se o salário informado for menor ou igual a R$1630,00, aplique um aumento de 15%. Se o salário for maior que R$1630,00 e menor ou igual a R$3000,00, aplique um aumento de 10%. Se o salário for maior que R$3000,00 e menor ou igual a R$5000,00, adicione um aumento de 5%. Se o salário for maior que R$5000,00, adicione um acréscimo de R$100,00. Exib'a para o usuário o salário atualizado.

### 6. Ordem Decrescente
Faça um programa que leia três números do usuário e mostre-os em ordem decrescente, utilizando estruturas condicionais.
